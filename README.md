# Trip Planner

Android-приложение для планирования поездок: маршрут по дням, бюджет с расходами по категориям и чек-лист вещей.

## Возможности
- Список поездок со статусом («Через N дней», «Идёт сейчас», «Завершена») и индикатором бюджета
- Маршрут: места и занятия по дням поездки, время и заметки
- Бюджет: расходы по категориям, остаток, предупреждение о превышении
- Чек-лист вещей со стандартным набором и прогрессом
- Светлая и тёмная темы

## Стек
Kotlin, Jetpack Compose (Material 3), Room (KSP), Navigation Compose, MVVM + StateFlow.

## Запуск
1. Откройте папку проекта в Android Studio (путь только латиницей).
2. Дождитесь Gradle Sync.
3. Запустите на эмуляторе или устройстве (Android 8.0+, minSdk 26).
